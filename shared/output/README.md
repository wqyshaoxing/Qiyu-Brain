# shared/output

通用成形。把结构化的东西变成人能读、能交付的形态。

## 准入门槛

- 不引入新信息，只改变形态。
- 输出可被机器再解析（结构化优先于纯文本）。
- 版式选择有理由，不是默认值。

## 候选

| 候选 | 解决什么 |
| --- | --- |
| doc-render | Markdown → DOCX / PDF，保留标题层级与图表编号 |
| figure-export | SVG / PNG / 矢量 PDF 导出与尺寸检查 |
| table-render | CSV / JSON → 可读表格，含单位与小数位规范 |
| translate | 中英互译，术语表锁定，保留引用标记 |
| diff-summary | 生成人可读的变更摘要 |

## 不该放这里

- 学科写作规范（期刊模板、参考文献格式）。
- 内容判断。这里只管形态。
