# shared/reasoning

通用判断方法。不绑定学科，但要求能说清判断依据。

## 准入门槛

- 方法本身可解释，不依赖「模型感觉」。
- 有可检验的中间产物（清单、矩阵、分级结果），不是一段结论文字。
- 允许「无法判断」作为合法输出。

## 候选

| 候选 | 解决什么 |
| --- | --- |
| evidence-grade | 证据层级划分：全文 / 摘要 / 二手引用 / 记忆，逐条标注 |
| contradiction-check | 冲突定位：先比较对象、条件、测量，再判是否真冲突 |
| fallacy-checklist | 常见推理错误清单：以偏概全、相关当因果、幸存者偏差 |
| option-matrix | 多方案按约束对比，含回退成本 |
| rigor-level | 由代价 × 可逆性决定严谨度档位 |

## 不该放这里

- 学科特有的方法学判断（统计功效、方法可行性）。
- 最终结论。这里只产出判断的结构。
