# shared/verify

通用核验。判断「做完了」还是「看起来做完了」。

## 准入门槛

- 有明确的通过与不通过标准，不是打分。
- 不通过时必须指出具体位置和原因。
- 不因为截止时间而放行。

## 候选

| 候选 | 解决什么 |
| --- | --- |
| citation-check | 引用与原文比对：存在性、是否支持、强度是否匹配 |
| reproducibility-check | 给定输入能否重跑出同样产物 |
| hash-review | 审查记录绑定当前文件哈希，防止产物被改后仍算通过 |
| format-lint | 结构检查：缺标题、空表头、断链、占位符残留 |
| claim-index-check | 正文断言与证据映射的双向覆盖 |

## 不该放这里

- 事实是否正确（那需要领域知识）。
- 语义质量评价（需要人或具备上下文的 agent 判断）。
