# _memory

跨任务可复用的沉淀。**只收 verify 通过的结论**，不收过程日志——过程日志属于 `.boomskills/runs/`。

## 为什么需要它

调研日志解决「这次怎么查的」，`_memory` 解决「下次不用重查」。没有它，每个任务都从零开始，学习不会累积。

## 何时写入

| 允许 | 禁止 |
| --- | --- |
| 有来源、有等级、可复核的事实 | 单次实验的中间结论 |
| 被证伪的假设（连同证据） | 没跑通的猜测 |
| 工具/库的真实坑与版本边界 | 会过期的操作步骤 |
| 某个领域的判断经验（适用条件明确） | 「一般来说应该」类空话 |

## 条目格式

一个主题一个文件：`_memory/topics/<slug>.md`，模板见 [TEMPLATE.md](TEMPLATE.md)。

```yaml
---
topic: 主题短名
scope: 适用条件，越具体越好
confidence: high | medium | low
evidence: [来源标识, ...]
reviewed: YYYY-MM-DD
expires: YYYY-MM-DD 或 never
---
```

正文固定三段：`Claim`（一句话结论）、`Evidence`（支持与反对的证据）、`Boundary`（什么情况下不成立）。

## 失效

- `expires` 到期后由使用者重核，不是自动删除。
- 新证据推翻旧条目时，保留旧条目并标 `superseded_by`，不静默改写。
- 与 `_memory` 冲突的新发现，优先信新证据，但必须同时更新条目。

## 隐私

健康记录、客户代码、未发表数据不进 `_memory`。只留可公开复述的结论，敏感细节留在私有工作区。
